# Review and 26.3 implementation notes

Current product direction: [vanilla resource pack shader authoring](vanilla-only-handoff.md); current source findings: [vanilla feasibility](vanilla-feasibility.md). The review below predates the implementation and is retained as historical evidence.

Historical review: the production v0.1 implementation and current validation status are documented in [the handoff](v0.1-handoff.md).

Reviewed baseline: `44b7f580894c76bd360030e3e739c833ed3e69ff`.

## Findings addressed

1. **No usable game output.** The baseline contained only CPU calculations and a browser image mock-up. Added a resource-pack compiler using the 26.3 post-effect activation mechanism, without claiming a Fabric client exists.
2. **Version-independent assumptions missed a new supported path.** 26.3 supports `minecraft:end_of_frame` and `/posteffect`. The earlier statement that arbitrary effects had no activation path was too broad for this version. The exporter now emits format 97.1 and location-qualified GLSL interfaces, references `minecraft:core/screenquad`, and uses typed blit configuration.
3. **Strong exposure flattened bright values.** Added a selectable exponential shoulder above 0.75 before clipping. Zero leaves existing looks unchanged. Vibrance weights saturation by remaining channel chroma headroom. Neither control promises to reconstruct already clipped source pixels.
4. **No preview/compiler agreement checks.** Extracted pure grading functions and added GPU comparison, neutral identity, alpha preservation, deterministic ZIP, target structure and unsupported-condition checks.
5. **Invalid numeric input could propagate NaN.** Hardened Java color, context and sample validation. Fixed the test assertion so NaN cannot pass as approximately equal. The editor also enforces ordered altitude bounds.
6. **Comparison/output workflow was limited.** Added split comparison, keyboard hold-to-compare, PNG download, clear export status, legacy project migration and a versioned target. Project v3 adds master/channel curves, histogram and clipping diagnostics, and undo/redo.

## Exact target contract

- Minecraft **Java 26.3**, resource pack format **97.1**, not an Iris/OptiFine shader pack.
- Always-on resource: `assets/minecraft/post_effect/end_of_frame.json`.
- Command resource: `assets/shader_maker/post_effect/grade.json`.
- Custom fragment: `assets/shader_maker/shaders/post/grade.fsh`.
- Full-screen grade samples `minecraft:main` into `swap`, then vanilla blit copies back. Never sample and write the same attachment in a pass.
- No custom vertex shader or unsupported core shader replacement.
- Current compiler supports static unconditional grading only. Context conditions must not disappear in transit.

## Evidence and limits

The [official 26.3 release notes](https://www.minecraft.net/en-us/article/minecraft-java-edition-26-3) establish pack format, activation and shader interface changes. Interface details were inspected against version-tagged extracted assets:

- [26.3 version metadata](https://github.com/misode/mcmeta/blob/26.3-summary/version.json)
- [vanilla creeper pass structure](https://github.com/misode/mcmeta/blob/26.3-assets/assets/minecraft/post_effect/creeper.json)
- [vanilla blit fragment and uniform block](https://github.com/misode/mcmeta/blob/26.3-assets/assets/minecraft/shaders/post/blit.fsh)
- [screenquad vertex interface](https://github.com/misode/mcmeta/blob/26.3-assets/assets/minecraft/shaders/core/screenquad.vsh)

Extracted assets establish interface expectations; they do not replace a loader test. Network access to the environment's proxy failed during this review, and no cached 26.3 client was available. No Minecraft smoke test or Fabric build is claimed. WebGL2 comparison translates only the version/precision declarations and input location syntax to validate fragment math on a software GPU. Minecraft's OpenGL and Vulkan ShaderC paths still need direct tests.

Next production milestone: compile/load this pack in a clean 26.3 instance, confirm color encoding and activation/removal, then implement the client editor against verified 26.3 APIs. Avoid copying older GLFW input or render hooks: this release uses SDL3 and revised render interfaces.
