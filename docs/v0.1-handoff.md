## Implemented

- Java 25 / Minecraft 26.3 Fabric client build with a production JAR and isolated development tooling.
- Title/pause menu entry and rebindable N key; responsive paginated editor, original/graded CPU specimen, five presets and all static grading controls.
- Master/channel curve graph: click/add, drag, numeric editing, keyboard nudging, deletion/reset, presets and 100-edit undo/redo.

- Atomic named saves, recoverable draft, paginated project library, and self-contained ZIP exports in automatic/command modes.
- Apply/disable using a generated preview resource pack and resource reload. Selection preserves other packs and is persisted. Reapplying an already selected preview pack is supported; the reload callback asks ShaderManager to load the compiled post chain before reporting success.
- Separate block-scraper screens and a capture script covering tabs, projects, curves, file actions and sizes/scales.

## Layer editor review (2026-11-02, dev client)

An adversarial in-game pass over the layers, conditions and sample-context screens. Evidence is in `shots/adv/` (before fixes) and `shots/fix/` (after). Everything below was driven through block-scraper; none of it is automated.

**How layers evaluate** (`Project.evaluate`): the base grade always applies. Each enabled layer re-grades the *original* image and crossfades over the running result by weight = strength × biome match × altitude weight × time weight. Weight 0 leaves the result below untouched; weight 1 fully replaces it. Later layers sit on top. It is a stack, not a tree; combine conditions on one layer for "desert AND night". Time ranges are circular over 24000 ticks (end before start wraps past sunrise) with smoothstep feathering up to 12000. Layers are sample-only: Apply/Export reject enabled layers until the live renderer exists.

**Fixed after the review** (all re-verified in game): the Conditions screen no longer traps Escape (Esc applies valid input; invalid input needs a second Esc or the new Cancel button); undo keeps you on the same layer unless the layer list changed; layer renames auto-save and invalid/duplicate names are rejected; layer and copy names are unique; long names get an ellipsis and keep the `[on, 100%]` status (full name in tooltip); status messages clear or fade (8 s in the editor); a **Disable all layers** button; the layer summary shows real biome/height/time values; corrected time help text; the preset label follows the actual grade; opening the editor starts on the base grade. German/locale testing was dropped; the mod is English-only (`en_us.json` only names the keybinding).

**Known, not fixed:** biome IDs are free text and not checked against the game (no registry outside a world); there is no collision-aware project save (names normalize to file names and overwrite); layer-list labels and all UI strings are hard-coded English.

**Not tested:** unsaved-change prompts on the Conditions screen beyond the Esc/Cancel flow, keyboard tab order, window resizing while a screen is open, Windows.
